# 建站提示词模板：生成 A 股热点事件日历

> 直接把下面这段发给 AI，即可让它生成一个与「A股热点事件日历」同构的日历应用。
> 可复制修改括号里的内容后使用。

---

## 模板（可直接复制）

```
请帮我生成一个「A股热点事件日历」网页应用。

【目标】
一个可交互的月历看板，支持点击任意日期查看该日的：农历/节气/节日、法定节假日或调休、
历史热点事件（最多3条）、未来重大事件预告，以及对应的 Excel 分析报告下载链接。

【功能要求】
1. 月历网格：6行×7列，支持上月/下月切换、回到今天；今天高亮；非当月置灰。
2. 农历与节日：内置 1900-2100 农历转换算法（公历→农历、干支、生肖），
   显示公历节日、农历节日、节气（清明/冬至等）、除夕。
3. 法定节假日/调休：放假显示红底「休」，调休上班显示橙底「班」。
4. 历史热点：已发生日期格子显示「热点」标记，点开可看当天最多3条热点标题，
   并提供「下载 Excel 分析报告」按钮（链接为该日 Excel 的公网下载地址）。
5. 未来事件：未来日期显示「热点」标记，点开显示可公布的重大事件/科技大事，
   支持跨多天事件，预计事件打「预计」标签。
6. 无 Excel 链接的日期显示「数据待生成」占位。
7. 底部保留免责声明：所有分析仅为题材推演，不构成投资建议。

【数据约定】（保证可被脚本继续消费）
- 日期键统一用 YYYY-MM-DD。
- 历史热点数据项：{ id, date, excelDownloadUrl, hotEvents:[{index,title,type}] }
- 未来事件数据项：{ id, startDate, endDate, title, description, isEstimated, category }
- 法定假期数据项：{ id, date, name, type:'holiday'|'workday' }

【输出形态】
交付零依赖单文件 index.html，双击浏览器即可打开使用；农历算法可单独提取为
独立 JS 模块便于复用。

【红线】
- 行情、事件、下载链接必须来自真实数据（用户提供或搜索获得），禁止编造。
- 不涉及任何投资建议承诺，保留免责声明。
```

---

## 使用说明

1. **填充数据**：把 `web/src/data/` 下三个数据文件的内容按模板结构填进提示词（或直接复制数据文件，让 AI 引用）。
2. **指定形态**：默认要求单文件 `index.html`；若你要 React 工程，把「输出形态」改为「Vite + React + TypeScript 工程」。
3. **校验**：生成后打开页面，抽查农历（如 2026 年春节日期）、节日、热点与下载按钮是否正常。
