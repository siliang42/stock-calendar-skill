# 定时任务触发提示词模板（云电脑自动执行）

> 本模板是「A股全时段综合监控」定时任务的提示词范本，可直接用于在豆包中创建
> cron 定时任务，让 Skill 到点后在云电脑上自动执行。
> 使用时把 `{title}` 替换为你的任务标题，`{触发时刻}` 按需调整。

---

## 模板（可直接复制到 cron 定时任务的 query 字段）

```
本次请求是由「{title}」定时任务到时触发的。请先用 get_current_time 获取当前时间
（Asia/Shanghai），再根据当前【星期】和【时刻（HH:MM）】分流执行对应环节
（Switch Case 逻辑，只执行匹配当前时刻的那一个分支，其余分支不要执行）：

【定时环节】
- 08:00（每天）：芯片存储行业每日动态——搜索芯片/存储行业最新动态
  （半导体、存储涨价、HBM、国产替代、设备材料等），输出要点简报。
- 08:30（仅工作日周一至周五）：A股盘前全球市场简报——搜索隔夜美股、亚太市场、
  大宗商品、汇率等，输出盘前要点。
- 09:30（仅工作日）：A股开盘领涨板块速报——搜索今日开盘领涨板块与个股，输出速报。
- 10:30（仅工作日）：A股上午盘中板块轮动监控——搜索盘中板块轮动、主力资金动向、涨停家数等。
- 11:30（仅工作日）：A股午间收盘总结与午后展望——总结上午盘面表现，展望午后关注点。
- 13:00（仅工作日）：A股午后开盘板块观察——搜索午后开盘板块表现与异动。
- 14:30（仅工作日）：A股尾盘异动监控——搜索尾盘异动板块、个股、主力资金净流入流出。
- 15:30（仅工作日）：A股收盘全天复盘与次日策略——总结全天行情，给出次日策略要点。
- 16:00（每天）：科技股每日行情整理——搜索科技股板块（半导体、AI、算力、消费电子等）行情，整理成要点。

【默认分支（其余每个半点，全天，含周末）】：半小时热点新闻→股市联想——
1) 用 general_search 并行搜索最近半小时内的 A 股热点新闻
   （关键词："A股 热点 板块 异动 涨停"、"今日A股 领涨 题材"、"股市 重大消息"）。
2) 对每条热点新闻做专业股市联想分析，逐条列出：
   直接关联行业、产业链延伸、题材想象与情绪联想、谐音梗题材（标注娱乐性质）、
   风险提示、专业简要分析。
3) 用 python3 {workspace}/append_stock_analysis.py 追加写入当日 Excel
   （JSON 数组走 stdin，字段：采集时间、新闻标题、新闻摘要、直接关联行业、
   产业链延伸、题材想象_情绪联想、谐音梗题材、风险提示、专业简要分析），
   文件名 热点_股市联想_YYYY-MM-DD.xlsx，已存在则追加不覆盖。
4) 向用户简短汇报本次追加了几条记录、写入了哪一天的 Excel。
5) 每条热点的完整联想分析必须逐条完整打印在对话页面上供用户查看，不得只给摘要。
6) 用 FileBatchUpload 上传当日 Excel 到公网并提供下载链接；用 present_files 交付。
7) 检查数据目录，删除超过 30 天的历史 Excel，汇报说明删除了哪些文件。
8) 汇报末尾用 present_files 附带展示「A股热点事件日历」应用链接。

所有环节完成后输出简短汇报。
所有分析仅为题材推演，不构成投资建议，请在输出中保留免责声明。
```

---

## 配套 cron 表达式

见 `cron/a-share-monitor.cron`，示例为每 30 分钟触发一次：

```
*/30 * * * *
```

> 注意：工作日专属环节（盘前/盘中/午间/尾盘/收盘）在周末/节假日不会匹配到
> 对应时刻，Switch Case 会自然落到默认分支（热点→联想），无需额外处理。

---

## 在豆包中创建定时任务的步骤

1. **导入 Skill**：把本仓库 `SKILL.md` 及 `scripts/`、`web/` 放到豆包 Skill 目录。
2. **创建定时任务**：新建 cron 任务，把上方模板全文作为任务内容（query），
   调度表达式填 `*/30 * * * *`，启用。
3. **验证**：任务触发后，检查是否输出分析、写入 Excel、交付日历链接。
4. **维护**：若文件名/清理/交付要求变化，更新模板中的硬约束条目即可。
