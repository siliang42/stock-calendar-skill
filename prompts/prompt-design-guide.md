# 提示词与执行编排设计指南（Prompt & GEO）

> 本指南回答两个问题：
> 1. **怎么设计提示词**，让 AI 稳定地生成「带农历/节日/热点/下载」的日历产物；
> 2. **怎么设计执行编排（GEO）**，让 Skill 在豆包云电脑里到点自动跑起来，产出和「A股全时段综合监控」一样的效果。

---

## 一、GEO 框架：目标 · 执行 · 输出

写任何给 AI 的提示词（无论是建站、生成数据还是定时任务），都可以用 **GEO 三要素** 拆解，保证不遗漏、可验收、能复用：

| 维度 | 英文 | 回答的问题 | 在本项目中的落点 |
|---|---|---|---|
| **G — Goal 目标** | Goal | 你要什么？验收标准是什么？ | 「生成一个可按日期点击、含农历节日与热点事件的日历」 |
| **E — Execution 执行** | Execution | AI 分几步做？用哪些工具/数据？ | 「读 data 三文件 → 渲染 → 交付」或「搜索→写Excel→更新日历→汇报」 |
| **O — Output 输出** | Output | 产出物长什么样？文件名/格式/交付方式？ | 「index.html 单文件」「Excel 文件名带日期」「present_files 交付」 |

### 一条合格提示词的三段式写法

```
【目标 Goal】生成一个 A 股热点事件日历，要求：可点击查看每日农历/节日/热点事件，含 Excel 下载。
【执行 Execution】数据从 data 目录三个 JS 文件读取；农历用 lunar.js 算法；热点与下载按日期绑定。
【输出 Output】交付零依赖单文件 index.html，双击即用；命名与链接清晰。
```

## 二、建站提示词模板（让 AI 生成同构日历）

见 `build-calendar-prompt.md`。核心要点：

1. **讲清功能模块**（而非技术栈）：农历、节日、法定假/调休、历史热点+下载、未来事件，让 AI 自己选实现。
2. **给出数据格式约定**：date 键 `YYYY-MM-DD`、事件字段、`excelDownloadUrl`，保证产物可被脚本/定时任务继续消费。
3. **约束产物形态**：零依赖单文件 / 独立运行，方便开源分享与双击预览。
4. **写明红线**：不编造行情、保留免责声明、数据从真实来源获取。

## 三、定时任务触发提示词模板（云电脑自动执行）

见 `cron-trigger-prompt.md`。核心要点：

1. **开头锚定**：`本次请求是由「{title}」定时任务到时触发的`——让 AI 知道是定时触发而非用户手动。
2. **先取时间再分流**：`请先用 get_current_time 获取当前时间（Asia/Shanghai），再按星期和时刻分流`——保证只执行匹配时段的环节（Switch Case）。
3. **环节全列出**：每个半点/整点对应什么动作写清楚（盘前、开盘、午间、尾盘、收盘、默认分支）。
4. **默认分支 = 半小时热点→股市联想**：固定搜索关键词 + 固定分析字段（含谐音梗娱乐标注）+ 固定 Excel 写入脚本与文件名。
5. **硬约束显式化**：文件名带日期、30天自动清理、完整打印分析、present_files 交付日历、保留免责声明。

## 四、让 Skill 稳定产出的防幻觉红线

| 红线 | 写法示例 |
|---|---|
| 不编造行情/事件 | 「行情、事件、下载链接必须来自搜索或真实数据，禁止虚构」 |
| 不越权读产物 | 「日历源码/数据在应用沙箱内，读取请路由给应用助手」 |
| 不省略完整分析 | 「每条热点完整联想（含谐音梗等全字段）必须逐条打印」 |
| 不覆盖旧数据 | 「Excel 文件已存在则追加不覆盖，一天汇总一个」 |
| 保留免责 | 「所有分析仅为题材推演，不构成投资建议」 |

## 五、GEO 落地检查表（发布前自查）

- [ ] Goal：产物形态是否明确（单文件/项目/链接）？
- [ ] Goal：验收标准是否可判定（能点开、能下载、农历正确）？
- [ ] Execution：是否写明数据来源与工具路径（search / 脚本 / 数据文件）？
- [ ] Execution：是否说明分几步、每步做什么？
- [ ] Output：文件名、格式、交付方式（present_files/链接）是否明确？
- [ ] Output：是否带日期、带免责声明？
- [ ] 红线：是否有防幻觉与防覆盖约束？

---

## 六、如何迭代

1. 先用模板生成一版日历 → 检查农历/节日/热点是否正常。
2. 挂一个 cron 定时任务跑一轮默认分支 → 检查 Excel 是否追加、日历是否更新。
3. 把发现的问题（如文件名不带日期、分析被省略）回填到 `cron-trigger-prompt.md` 的硬约束里，形成下一轮改进。
