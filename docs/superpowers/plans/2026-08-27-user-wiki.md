# A 股热点事件日历用户 Wiki Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增一套任务导向、可直接同步到 GitHub Wiki 的首次使用者文档。

**Architecture:** `wiki/Home.md` 与 `wiki/_Sidebar.md` 提供统一入口，六个主题页分别覆盖上手、安装、更新、自动化、参考和排错。所有操作以当前源码和脚本为事实来源，页面通过 GitHub Wiki 页面名互链。

**Tech Stack:** GitHub Flavored Markdown、Python 3、shell、现有 `openpyxl` 脚本。

## Global Constraints

- 主要读者是首次使用者，内容以任务和可执行命令为中心。
- 不修改业务代码、业务数据或现有构建产物。
- 不把豆包平台能力写成普通 Python 能力。
- 不把仓库中不存在的 `scripts/run_tick.sh` 写成可直接执行入口。
- 命令默认从仓库根目录执行；所有参数必须与当前脚本一致。
- 示例热点、节假日和公网 URL 必须明确标记为示例或替换项。
